# X / Twitter 轮播图展开 (画质与体积优化版)

选择 X（Twitter）帖子中的图片，按智能排版、横向、纵向或网格排版，复制到剪贴板或下载。支持 JPEG、PNG、WebP，以及质量、尺寸和文件大小预估。

## 6.5.1 更新

- 预览、复制和下载共用已加载的原图数据。
- 同一张图片尚未加载完成时，导出会等待已有请求，不再重复下载。
- 更改格式、质量、尺寸或排版后，继续复用已加载的图片。
- 复制回退为 PNG 时，也不再重复下载原图。
- 关闭弹窗后释放图片缓存；重新打开时重新加载。

已加载的图片仍需在本地拼接和编码。尚未加载或加载失败的图片会在需要时请求。

## 6.5.0 更新

- 新增“智能排版”，按图片比例自动分行，每行铺满宽度。
- 图片保持原比例和原帖顺序，图片之间不留间距。
- 末行参与整体排版，减少单张图片独占末行的情况。
- 预览、复制和下载共用同一布局。
- 横向、纵向、两列和三列仍可选择，保留已有排版设置。

在弹窗顶部的“排版”中选择“智能排版”。选择或取消图片后，布局会重新计算。

智能排版会等比调整每张图片的尺寸。100% 表示完整排版尺寸，75%、50% 和 25% 在排版尺寸上缩小。WebP 尺寸上限和导出宽高检查继续生效。

## 6.4.1 更新

- 修复超长 WebP 导出后底部缺失的问题。
- WebP 的宽或高超过 16383 px 时，预览会提示降低尺寸或改用 JPEG/PNG。
- 导出前检查格式尺寸限制，编码后再次检查文件宽高。
- 文件宽高与排版不一致时，停止复制和下载并提示重试。

20 张图片按两列排版时，合成图可能超过 WebP 的尺寸上限。选择 JPEG 可保留原尺寸；选择 WebP 时，可降低尺寸后导出。

## 6.4.0 更新

- 顶部编号方块与图片逐一对应，默认选中前 4 张。
- 点击编号方块或图片可选择、取消选择，也可全选或清空。
- 选中的图片显示细光泽边框，未选图片放在下方。
- 复制和下载只包含已选图片，顺序与原帖一致。
- 排版支持横向、纵向、两列和三列，预览与导出使用同一布局。
- 图片保持原比例，不裁切；网格未填满的位置会留空。
- 新增 25% 缩放档位，限高选项按整张拼接图计算。
- 导出逐张解码图片，绘制后立即释放。

边框和编号只用于预览，不写入导出图片。排版会保留到下次打开，图片选择每次重置为前 4 张。

文件大小为估算值，不能保证符合所有平台的发送限制。图片过大时，可减少选择或降低尺寸。WebP 单边上限为 16383 px。JPEG/PNG 单边超过 32767 px，或任意格式总像素超过 6400 万时，脚本会提示调整后重试。

## 6.3.0 更新

- 图片预览改用白色工具栏和浅灰画布。
- 图片区单独滚动，格式、质量、尺寸和操作按钮始终可见。
- 原生弹窗管理焦点，关闭后返回展开按钮。
- 动态推文分批处理，图片后加载时也能补上展开按钮。
- 下载或编码失败后释放已解码图片。
- 缩放拼接使用累计边界，避免舍入产生空隙。
- 浏览器拒绝存储时，设置仍在本次页面中生效。

导出图片时显示进度条；复制和下载按钮暂时不可重复操作。
剪贴板回退为 PNG 时，状态显示实际写入的文件大小。

## 桌面宽屏布局

- 页面宽度达到 1000 px 时，左侧导航贴左显示。
- 右上角保留 X 原生搜索框和搜索建议。
- 隐藏趋势、推荐关注、订阅推荐和页脚链接。
- 点击右下角的“切换宽度”按钮，可依次切换内容宽度。
- 推文正文和图片随信息流一起展开。

| 模式 | 内容宽度 |
| --- | --- |
| 标准 | 上限 600 px |
| 加宽 | 上限 960 px，默认选择 |
| 全宽 | 填满导航栏右侧的空间 |

标准和加宽模式在导航栏右侧居中显示。
可用空间不足时，内容宽度会自动缩小。
脚本记住宽度选择，刷新页面后仍然生效。

页面宽度小于 1000 px 时，脚本保留 X 原有布局。
宽屏布局使用 X 的页面标识匹配，适用于包含信息流主栏的页面。

已有脚本可在油猴管理面板中替换代码并保存，然后刷新 X 页面。

## ✨ 核心特性

- 🖼️ **原图质量获取**：自动解析推文原图资源（`name=orig`），拒绝缩略图模糊失真。
- **选择与排版**：支持 20 张图片的选择，按智能排版、横向、纵向、两列或三列导出。
- ⚙️ **多格式与画质控制**：
  - **格式选择**：支持 JPEG（推荐）、PNG（无损原画）、WebP。
  - **质量滑块**：30% ~ 100% 自由微调压缩率。
  - **尺寸缩放**：原图 / 75% / 50% / 25% / 限高 1080 px / 限高 1440 px。
  - **体积预估**：悬浮工具栏实时预估生成后的大小，清晰掌控文件体积。
- 📋 **智能剪贴板适配**：
  - 自动适配现代浏览器 Async Clipboard API 规范。
  - 当浏览器底层限制仅允许写入 PNG 时，脚本会自动执行兼容性降级，确保在微信、QQ、Discord 等软件中粘贴顺畅。
- 💾 **一键本地保存**：支持直接导出完整拼接图片文件到本地磁盘，不受系统剪贴板体积和格式约束。

## 💡 常见问题与说明

### Q: 为什么复制时显示“已复制为 PNG”？
* **原因**：现代浏览器（Chromium / Firefox / Safari）出于内存安全和跨平台剪贴板标准规范，限制向系统剪贴板写入压缩格式（如 JPEG / WebP），默认只允许写入 `image/png`。
* **说明**：脚本探测到浏览器拒绝写入 JPEG 时，会自动无损回退并以 `image/png` 格式写入，确保你在微信、QQ、Office 等软件中能正常 `Ctrl + V` 粘贴出来。
* **建议**：
  1. 日常直接复制：可直接在顶部将格式切换为 **PNG**，脚本会自动记住设置，今后复制将不再弹回退提示。
  2. 需要 JPG 文件时，选择 JPEG 格式，再点击右上角的“下载所选”。
